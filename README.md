## What it does

`main.py` writes one safety warning label to `/output/entry.txt`. The program is deterministic (the same
bytes on every run), uses no network, and needs no input.

The line:

> WARNING: Contents: one human. May leak feelings without warning, overheat in small talk, and shut down without saving.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
